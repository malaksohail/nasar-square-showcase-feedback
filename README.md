# Nasar Square showcase feedback

This public inbox is for suggestions about the interactive showcase. Use Issues to share the view you tried, what you expected, and what you would change. Please omit personal information, account details, and store or payment records.

## Showcase backlog

- Collect feedback about navigation, sample checkout, and the storefront concept.
- Review similar submissions together and check for duplicates.
- Reproduce useful improvements in the showcase before proposing an engineering issue.
- Move approved changes through normal product review without linking production systems to this inbox.

This inbox is separate from the POS development repository and its private data.
